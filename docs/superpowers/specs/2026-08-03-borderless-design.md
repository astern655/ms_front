# Borderless — 설계 스펙

작성일: 2026-08-03
상태: 구현 중 (React + Vite)

## 한 줄 정의
팀의 경계에 맞춰 튜닝되는 AI 협업 제품. 화상회의에서 **언어·수화 장벽을 실시간으로 없애고**, 회의록을 남겨 다운스트림(요약·번역·wiki·실행)이 소비하게 한다.

## 이번 스펙의 범위 (중요)
이 문서는 **"실시간 번역 레이어"** 한 조각만 다룬다.
- ✅ In-scope: 화상회의 + 거의 실시간 번역 자막 + 수화 인식 자막 + 회의록(transcript) 저장
- ❌ Out-of-scope (별도 작업): AI 에이전트, 회의 요약, 참가자별 사후 번역, llmwiki, "proceed" 자동화, 온보딩 프로필
  - 이들은 **저장된 transcript를 입력으로 받아** 독립적으로 개발한다. 인터페이스 = transcript 파일/레코드.

## 테마 적합성 (심사 기준)
- **보더리스**: 언어(음성) + 수화(접근성)를 실제로 넘음. 특히 수화 = "말·듣지 못하는 사람의 회의 배제"라는 가장 깊은 경계.
- **AI 활용**: STT·번역·수화 인식이 전부 AI. 빼면 제품이 성립 안 됨.
- **협업**: 제품 자체가 협업 도구. 회의록으로 "함께 일한 흔적"이 남음.

## 아키텍처 (독립 유닛)
```
[브라우저 A]  [브라우저 B] ... ─── LiveKit 룸 (화상 + data 메시지)
   │  마이크 오디오                         ▲ 자막 브로드캐스트
   ▼                                        │
[백엔드 STT/번역 서비스] ── OpenAI (STT + 번역) ┘
   │
   ▼  카메라 프레임(로컬)
[MediaPipe 수화 인식 (브라우저)] ── 큐레이션 어휘 분류기 → 자막
   │
   ▼
[Transcript 저장소] ── 다운스트림(에이전트/wiki)이 소비하는 인터페이스
```

- **Video Room** — LiveKit 룸 참가/화상 렌더/자막 data 메시지 송수신. (Agents 프레임워크 미사용)
- **STT+Translate 서비스** — Vite dev 미들웨어(`/api/stt`). 오디오 청크 → OpenAI STT → 대상 언어 번역 → 자막 텍스트 반환. OpenAI 키는 여기서만 보관. (배포 시 독립 서버 필요)
- **Sign Recognition** — 브라우저. MediaPipe Holistic 랜드마크 → 큐레이션 어휘 분류기 → 자막 텍스트.
- **Caption Layer** — 음성 자막 + 수화 자막을 각 참가자의 선택 언어로 렌더.
- **Transcript Store** — 자막 스트림을 시간순으로 누적 저장(발화자·원문·번역·타임스탬프).

## 데이터 플로우
1. 참가자가 룸 입장, 각자 표시 언어 선택.
2. 마이크 오디오 → 백엔드 → STT(원문) → 번역(각 대상 언어) → LiveKit data 메시지로 자막 브로드캐스트.
3. 농인 참가자 카메라 → MediaPipe → 어휘 인식 → 자막으로 동일 경로 합류.
4. 모든 자막을 transcript로 저장. 회의 종료 시 다운스트림이 이 transcript를 가져감.

## 기술 스택
- 프런트: **React + Vite + TypeScript** + LiveKit React 컴포넌트
- 실시간: LiveKit (SFU, Cloud 무료 티어 or self-host)
- 백엔드: **Vite dev 미들웨어**(`/api/token`, `/api/stt`) — dev 전용, 키를 서버사이드에 보관. 배포 시 독립 서버(Express/Hono 등)로 분리 필요.
- AI(외부 API): **OpenAI** — STT(`gpt-4o-transcribe`), 번역(`gpt-4o-mini`). 지연 부족 시 gpt-realtime-translate 검토.
- 수화: MediaPipe Holistic(브라우저 JS) + LSTM 계열 큐레이션 어휘 분류기 (SLRNet / metehanozdeniz 구조 참고, KSL-Guide 데이터셋 참고)

## MVP 범위 (2주) & 컷라인
- ✅ 빌드: 2~3인 화상 룸 / 실시간 번역 자막 / 수화 인식 자막(큐레이션 어휘 수십 개) / transcript 저장
- 📋 로드맵: 견고한 양방향 수화, 3D 아바타, 온보딩 프로필, 에이전트·요약·wiki·자동화

## "거의 실시간"의 정직한 천장
- 번역 자막: 약 1~3초 지연 (캐스케이드 STT→번역). gpt-realtime로 단축 가능.
- 수화: 큐레이션 어휘는 거의 즉시. 자유 문장 통역 아님 — "작동 어휘 내에서" 정직하게 표기.

## 리스크 / 의존성
1. 수화 실시간 인식 정확도 (최대 리스크) → 어휘 큐레이션·데모 시나리오 고정으로 완화.
2. STT 다국어·잡음 성능.
3. 자막 지연.
4. LiveKit / OpenAI 외부 서비스 의존 (키·비용·요율).
5. 브라우저 카메라·마이크 권한/성능.

## 결정된 사항
- 지원 언어 초기 세트: **한국어 + 영어** (베트남어는 여유 시)
- 수화: **KSL(한국 수어)**, 데모 큐레이션 어휘
- transcript 저장 형식: **JSON**(발화자·원문·번역·타임스탬프) — 다운스트림 계약
- LiveKit: **Cloud 무료 티어**
- 프레임워크: **React + Vite** (Next.js 아님)
